# Stream Effects Studio

Local effects for VTube Studio on Windows: Waterfall, Bonk, Horny bonk, and Sparkles, with customizable presets and Mix It Up triggers.

## Install

Get the installer EXE from [the latest release](https://github.com/mpwrightt/stream-effects-studio-releases/releases/latest). The release also includes a quick-start guide and asset credits.

The installer includes the app runtime and assets. Open VTube Studio, install the app, and follow its connection setup. VTube Studio requires one-time plugin approval and adding/pinning a transparent Web Item.

Windows x64. The installer is currently unsigned.

## Automatic updates

Starting with 0.2.0, new versions download automatically in the background and install silently the next time the app opens. Updates never force a restart while the app is running. Saved presets, imported assets, and local connection settings carry over.

No GitHub account is needed. This repository distributes installers, update metadata, guides, and release notes.
